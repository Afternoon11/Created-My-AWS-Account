# AWS Account Setup — Learning Log

A beginner learning log documenting my first exploration of the AWS console, account settings, credential-management pages, and AWS Free Tier information.

## Objective

Become familiar with the AWS console and locate the account settings and learning resources needed to start working with AWS services.

## Activities

1. Opened AWS Settings and reviewed account and project-management options.
2. Explored the profile menu and console navigation.
3. Visited credential-management resources to understand where account credentials are managed.
4. Reviewed AWS Free Tier information and introductory service options.

## Key Takeaways

- The AWS console provides access to cloud services and account settings.
- Account credentials must be protected carefully.
- Free Tier eligibility and usage limits should be reviewed before creating resources.
- Access keys and passwords must never be committed to a Git repository or shared in screenshots.

## Security Checklist

- Enable multi-factor authentication.
- Protect root-user credentials and avoid using the root user for everyday tasks.
- Prefer IAM roles and appropriately scoped access.
- Never publish access keys, secret keys, recovery details, or billing information.
- Monitor usage and billing to avoid unexpected charges.

## Learning Outcome

This activity helped me become familiar with the AWS account interface and identify the account resources I will use while learning cloud computing.

---
This repository records account-navigation learning only. It does not contain or publish AWS credentials.
